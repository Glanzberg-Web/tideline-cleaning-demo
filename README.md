# Tideline Home Cleaning — Website Demo

Tideline Home Cleaning is a fictional residential-cleaning brand created by **Glanzberg Web** as a portfolio demonstration.

This concept shows how a home-cleaning company can present services, build trust, and guide visitors toward a quote request with a simple, polished mobile-first website.

## Demo highlights

- Responsive one-page cleaning-service website
- Bright, minimal visual direction
- Recurring, deep-clean, and move-in/move-out service packages
- Trust and process sections
- FAQ-style reassurance content
- Quote-request form demonstration
- Static structure ready for GitHub Pages

## Important

Tideline Home Cleaning is not a real business. Names, testimonials, service details, statistics, phone numbers, availability, and other business information are sample content used solely for demonstration.

The quote form is intentionally configured as a demo and does not send information to a real cleaning company.
